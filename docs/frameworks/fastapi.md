# FastAPI

> Modern, fast (high-performance), web framework for building APIs with Python based on standard Python type hints

## Official Resources

- [FastAPI Documentation](https://fastapi.tiangolo.com/) - Comprehensive official documentation with tutorials and guides
- [FastAPI GitHub](https://github.com/tiangolo/fastapi) - FastAPI source code and issue tracking
- [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/) - Step-by-step guide to building APIs with FastAPI

## Learning & Tutorials

- [Full Stack FastAPI Template](https://github.com/tiangolo/full-stack-fastapi-template) - Official full-stack project generator with React, PostgreSQL, Docker
- [FastAPI Best Practices](https://github.com/zhanymkanov/fastapi-best-practices) - Opinionated list of best practices and conventions
- [FastAPI Course](https://testdriven.io/courses/tdd-fastapi/) - Test-driven development with FastAPI and Docker
- [Awesome FastAPI](https://github.com/mjhea0/awesome-fastapi) - Curated list of FastAPI resources and projects

## Database Integration

- [SQLAlchemy](https://www.sqlalchemy.org/) - SQL toolkit and Object Relational Mapper with FastAPI integration
- [Tortoise ORM](https://tortoise.github.io/) - Easy-to-use asyncio ORM inspired by Django
- [Piccolo](https://piccolo-orm.com/) - Fast, user-friendly ORM and query builder with async support
- [Databases](https://github.com/encode/databases) - Async database support for PostgreSQL, MySQL, and SQLite
- [SQLModel](https://sqlmodel.tiangolo.com/) - SQL databases with Python objects using Pydantic and SQLAlchemy

## Authentication & Security

- [FastAPI Users](https://github.com/fastapi-users/fastapi-users) - Ready-to-use and customizable users management

- [Authlib](https://authlib.org/) - Ultimate Python library for OAuth and OpenID Connect
- [Python-JOSE](https://github.com/mpdavis/python-jose) - JavaScript Object Signing and Encryption for JWT

## Testing

- [Starlette TestClient](https://www.starlette.io/testclient/) - Built-in test client for FastAPI applications
