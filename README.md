## Welcome

Welcome to **Awesome Learning** - your one-stop resource for discovering high-quality libraries, frameworks, and tools across multiple technology stacks. Whether you're building a modern web application, crafting APIs, or automating workflows, you'll find curated resources to accelerate your development journey.

## What's Inside

This collection covers 8 essential technology ecosystems:

### 🎨 Frameworks

- **[React](docs/frameworks/react.md)** - UI library with state management, components, and tools
- **[Next.js](docs/frameworks/nextjs.md)** - React framework for production with server-side rendering
- **[FastAPI](docs/frameworks/fastapi.md)** - Modern Python web framework for building APIs
- **[Django](docs/frameworks/django.md)** - High-level Python web framework for rapid development

### 💻 Languages

- **[JavaScript](docs/languages/javascript.md)** - Essential JS tools, utilities, and build systems
- **[TypeScript](docs/languages/typescript.md)** - Typed JavaScript resources and type utilities
- **[Python](docs/languages/python.md)** - Python libraries for web, data science, and more
- **[Bash](docs/languages/bash.md)** - Shell scripting tools, CLI utilities, and productivity

## Why Awesome Learning?

- ✅ **Curated Quality** - Only actively maintained, well-documented resources
- ✅ **Organized Structure** - Easy to navigate by technology and category
- ✅ **Community Driven** - Open to contributions from developers worldwide
- ✅ **Practical Focus** - Resources that solve real-world development challenges
- ✅ **Regular Updates** - Continuously updated with the latest tools and libraries

## Quick Start

1. Browse by **[Framework](docs/frameworks/)** or **[Language](docs/languages/)**
2. Use the **search** feature (top right) to find specific libraries
3. Click on any resource to learn more
4. **[Contribute](CONTRIBUTING.md)** your favorite tools and libraries
